# Proposal

## Why

用户已授权正式实施数字芙宁娜，并允许自主选择首版路线。当前只有本地 PMX 资产和准备材料，需要先建立动作、真实发声和共同经历跨会话保存的可运行闭环，为后续自然对话和成长改进提供实测基础。

## What Changes

- 本机网页显示真实 PMX，提供待机、眨眼、招呼、点头及口型调度。
- 提供系统 TTS 与替换接口，清晰标明系统声不是角色原声，不使用未授权训练音频。
- 本地会话与共同经历存储、回忆、纠正和删除；展示证据与来源。
- 模型服务接口与芙宁娜角色提示，服务不可用时明确显示有限的本地演示模式，避免伪称自然语言模型已经接入。
- localhost 运行、安全资产服务、可复现启动、真实测试记录和阶段交接。
- 分阶段 commit/push 到用户指定仓库，排除受限制资产、个人记忆、音频和凭证。

## Capabilities

### New Capabilities

- `character-stage`: 本地模型加载、动作、口型与可替换真实发声。
- `shared-memory`: 共同经历的持久化、来源、回忆、纠正和删除。
- `local-conversation`: 角色对话、模型适配、故障回退与本机服务边界。

### Modified Capabilities

无现有主规格。

## Impact

新增 Node.js 本地 HTTP 服务、SQLite 存储、Three.js 网页与浏览器 TTS。角色资产只留本机，不引入 D_sakiko 代码；其 GPL-3.0 仅作为参考项目许可记录。首阶段不包含声纹训练、物理仿真、ASR 或公网部署；这些是后续工作，不取消用户最终需求。
