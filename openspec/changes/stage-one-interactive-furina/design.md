# Design

## Context

见 proposal.md。Node 24 可用，PMX 2.0 骨骼与嘴部 morph 完整，Edge 可用；Python/FFmpeg 和已运行的本地 LLM 尚未找到。GPU 为 8 GiB RTX 4060 Laptop。本地资产不能二次配布。

## Goals / Non-Goals

**Goals:** localhost 可运行交互切片；响应、发声、动作、记忆链路分别显示状态，使用实际文件和数据测试。

**Non-Goals:** 第一阶段不声称完成自然语言智能、原声复刻或稳定人格成长；不引入未经许可的音频，不启动公网服务。用户最终 AI 目标由后续阶段继续完成。

## Decisions

1. Node HTTP + SQLite（Node 内建 node:sqlite）服务，Three.js r160 MMDLoader 浏览器渲染。其 MIT 依赖支持现有 PMX，不需要先转换到其他模型格式或安装引擎。保留骨骼初始姿态，叠加程序动作；不启用 Ammo 物理以先核验稳定动作。
2. 浏览器 speechSynthesis 提供系统 TTS，接口独立于模型和记忆。播放状态控制口型，时间驱动为近似振幅而非声学音素同步，明确记录这个限制。声音列表依赖系统安装；无语音时报告错误。
3. SQLite 保存事件与显式共同经历。事件是来源，记忆是用户确认的摘录；首版不自动将 LLM 自述写成事实。基于文字检索相关记忆并回传 ID；编辑清除旧来源上下文，删除清理来源和衍生回复。后续可加语义检索与反思。
4. 默认有限规则演示，模型和密钥均为空。提供 OpenAI/GPT、GLM、DeepSeek、Kimi/通用兼容端点、Claude Anthropic 专用协议和 loopback Ollama 适配；当前阶段不自动连收费端点，远程请求需要明确开启授权开关。密钥只保留在用户当前页面内存及当前请求，不持久化、不读取其他应用。协议测试使用本地替身。对角色提示采用芙宁娜经历后的私人互动风格，允许用户后续调整起点。
5. HTTP 仅绑定 127.0.0.1；校验 Host/Origin、拒绝跨源写操作和路径越界，限定静态根目录，资源以显式路由提供。资产目录、数据目录和测试截图不进 Git。
6. 不复制 D_sakiko 代码。参考其公开架构，GPL-3.0 许可先记录，避免在本阶段引入复用许可义务。采用的直接依赖保留 package-lock 与许可证记录。

## Risks / Trade-offs

- [系统 TTS 声音非原声且可用性不同] → UI 标明、可选择/试听；后续研究合法可用语音服务。
- [无本地 LLM 时自然对话不达最终目标] → 坦诚展示规则演示，接口与提示先就绪；将真实模型接入作为接力优先任务。
- [PMX 渲染及动作依赖骨骼方向] → 浏览器截图和骨骼姿态实测后调整，不能仅凭结构扫描验收。
- [中文词检索局限] → 明确保存入口、列表和原始来源；固定脚本验证跨重启、纠错、删除，再扩展语义记忆。
- [程序口型近似且无物理] → 第一阶段记录效果限制，不能声称精准同步或布料仿真。

## Migration Plan

用用户现有 main 提交为父提交接入本地工作，不覆盖远程。安装 npm 锁定依赖，运行本地服务；所有运行数据保留于忽略目录。回退代码用普通 Git revert，保留资产与数据。交接通过 handoff.md 和测试记录，不依赖聊天历史。
