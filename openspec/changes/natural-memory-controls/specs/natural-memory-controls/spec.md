# Spec Delta

## ADDED Requirements

### Requirement: 自动记忆可查看纠正删除
系统 SHALL 展示自动整理的共同经历及可用来源，提供纠正与删除入口，不要求用户逐条点击保存才能形成记忆。

#### Scenario: 用户纠正
- **WHEN** 用户修改自动记忆草稿
- **THEN** 仅显式保存才提交，取消不写入，失败保留草稿供重试

#### Scenario: 用户删除
- **WHEN** 用户选择删除
- **THEN** 先要求确认，确认成功后刷新；失败保留记录和重试入口

### Requirement: 操作可靠性与真实接入
系统 MUST 阻止重复修改提交并拒绝迟到列表覆盖。未确认接口合同 MUST 不猜API或宣称已接生产管理。

#### Scenario: 重复点击与离开页面
- **WHEN** 操作中重复提交或离开页面
- **THEN** 只提交一次，离开后取消待处理请求并拒绝迟到呈现

#### Scenario: 接口尚未确认
- **WHEN** 只有呈现模块和假适配器
- **THEN** 隔离验证呈现状态，正式页面不接未确认的端点，交接明确未接线
