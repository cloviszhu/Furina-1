# Spec Delta

## Purpose

为本地角色舞台提供可替换的成熟语音合成能力，在保持参考录音许可、私人素材不外传和资源边界的同时，让用户明确选择声线与表达，并区分真实部署结果与尚未完成的角色相似度验收。

## ADDED Requirements

### Requirement: 本地成熟声音与诚实状态

系统 SHALL 支持本机成熟 TTS 后端并返回可播放音频；缺少部署或允许的参考录音时 MUST 明确报告原因，系统声 SHALL 作为标注的临时备用。角色相似度与表达质量 MUST 由真实 baseline 记录，不能由模拟测试替代。

#### Scenario: 后端不可用
- **WHEN** 成熟后端未运行或未配置 reference
- **THEN** 用户看到不可用原因，仍可显式选择系统备用声，系统不静默把备用声称为角色原声

### Requirement: 参考与表达分离

系统 SHALL 通过本地登记 ID 选择有来源/许可说明的参考录音，并用独立字段选择表达；不支持的表达 SHALL 拒绝，控制标签 MUST 不插入朗读文本。

#### Scenario: 未登记参考或表达
- **WHEN** 请求任意文件路径作为参考或未登记表达
- **THEN** 请求被拒绝且不会调用 TTS

### Requirement: 有界队列与取消

系统 SHALL 限制排队任务并串行访问共享推理核心，取消后 MUST 停止播放并忽略迟到音频；上游仍执行的任务 MUST 完成后再运行下一任务，并如实说明不具备 GPU 硬中断。

#### Scenario: 取消正在生成的任务
- **WHEN** 用户停止尚未完成的语音并请求下一句
- **THEN** 旧音频不播放，新任务等待旧推理释放资源，口型复位

### Requirement: 本地隐私与音频边界

系统 MUST 只向受限 loopback TTS 发送文本与登记 reference，拒绝重定向、外部端点和超限/无效音频，不读取或上传私人凭证与素材。

#### Scenario: 非本机端点或无效响应
- **WHEN** 配置外部地址或后端返回非 WAV/超限响应
- **THEN** 配置或响应被拒绝且对用户展示受控错误
