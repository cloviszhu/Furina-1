# Design

## Context
现有store重开/HTTP/浏览器测试分散；没有完整provider请求证据。普通远程配置自动降为offline，仅显式单次测试保存正式对话，18步批次不写正式记忆。

## Goals / Non-Goals
验证实际SQLite持久检索与来源链；不以mock正文验收长期记忆能力，不继续打磨人设，不部署。

## Decisions
- 固定mock仅返回无答案通用正文，正确资料仅经HTTP用户消息和保存进入SQLite。
- 用无关对话挤出历史窗口，关闭server/DB重开后问不含答案的问题；断言provider系统证据含实际检索条目而历史不含答案。
- 保存相同来源与相同正文幂等，保留不同来源及不同正文；UI请求在途阻止重复提交，取消未确认草稿无POST。
- 复用时间线历史隔离与来源校验；已确认记忆共享是既有行为，隔离范围未澄清前不改。

## Risks / Trade-offs
mock证明存取与组装，不证明真人模型对记忆准确性、自然度或长上下文理解。生产数据仅只读安全状态核对。
