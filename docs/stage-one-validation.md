## 修复与取舍

- 控制骨骼转动但网格不动：实际 PMX 变形依赖 grant，采用 Three 自带 solver，并断言真实 skinned vertex 位移，不只检查骨骼 quaternion。
- 纠错清理聊天会孤立共用来源的记忆：为其他确认记忆建立独立来源，增加回归测试。
- 模型路由和生产 `/assets/` 冲突：模型改用 `/character-assets/`。
- Node fetch 没按 Host 头模拟请求：改为原生 HTTP 验证拒绝非法 Host。
