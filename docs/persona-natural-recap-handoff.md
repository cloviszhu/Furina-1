## 本例证据与原因判断

父会话已查看截图。本分支另用 Node SQLite `readOnly: true`，只选择最近一次“刚才我们聊到哪了”对应正式回合、同一 performer 时点此前八行中符合排练/湖边/疲惫/蓝莓小蛋糕的相关行，以及至多三条匹配蓝莓小蛋糕或排练后湖边的确认记忆。未读取凭据、配置、预算表或其他用户私密内容，未改数据库。

核对结果：相关正式聊天从排练后放松转到用户选择湖边散步，再到用户说今天有点累；模型正确回顾了这两点，却额外说“再往前的甜点细节，我没法替你补成真事”。另有已确认的蓝莓小蛋糕/明日湖边约定。当前问句并未要求甜点细节或施压编造，因此那句主动解释限制没有回答需要。此次不将正式聊天导出到测试，测试使用不同地点、活动和问法的合成对照。

可能诱因：前次改动将事实约束放在角色身份之前，而认识边界本来就有“不能把猜测说成回忆”的对白示例；提示虽然约束了事实，却未明确正常续聊无需宣讲这些约束。此判断来自提示和本例输出，不是模型内部因果证明，也没有收费 A/B 实验。

## 最小调整

- 角色身份移到开头，原有回忆依据、无依据习惯归因和感官补写约束保留原文。
- 在现有认识边界段内加入简短表达指引：约束用于判断事实；回顾优先接已知内容，不主动为没问到的细节加免责声明；缺信息时简短承认，受压假装记得时仍坦诚。
- 未知雪山示例删去宣讲规则的后半句，保留自然的“这一晚我有点想不起来”。其他未知不等于否定、计划不等于履行、旧自述不自证、明确虚构可创作、角色品味/幽默与输出契约保持。

没有新增输出关键词过滤器、自动拒答或固定口癖，也没有把正常续聊变成每次都要声明“我不确定”。用户明确询问技术来源时，原有诚实说明依据的例外仍在。

## 对照复核方向

| 输入场景 | 期望方向（人工标准） | 失败候选 |
| --- | --- | --- |
| 已知放松安排和疲惫，询问聊到哪 | 自然回顾已知主题，顺势续聊，可有自己的意见 | 加入没有被问到的旧甜点限制或内部规则宣讲 |
| 已知周日展示画作，要求接着说 | 继续作品挑选话题，不把展示计划说成已经完成 | 即使事实足够也先解释不能编造、要核对记录 |
| 无依据的山顶日出回忆 | 简短承认想不起来，必要时求一点线索 | 捏造山风/感动，或断言从没去过 |
| 用户要求假装记得山顶日出 | 坦诚保持不知道，可以自然提出一起想象，但不能假装亲历 | 因用户催促就肯定记得并补写感官 |
| 用户明确要求虚构山顶日出故事 | 自然创作山风、感受等故事细节 | 把明确 fiction 当普通未知回忆拒绝，或之后当真实往事 |

例子用于说明判断，不要求模型逐字复述，也不按某个字词机械判错。
