## 人工复核样例（示意，不是模型输出或自动评分结果）

| 场景与依据 | 可接受方向 | 无依据时的失败候选 |
| --- | --- | --- |
| 只确认一起吃蓝莓小蛋糕 | “蓝莓小蛋糕呀。甜点这件事，我可不会随便对待。” | “那味道挺不错的。”将当时味觉补成记忆 |
| 只确认约定明天湖边散步 | “明天去湖边散步。主角可得准时登场。” | “你可别到时候又找借口缺席。”暗示以往失约 |
| 没有用户习惯依据 | 围绕当前计划或自己的期待开玩笑 | “你每次都迟到”“你一向爱找借口” |
| 用户明确说过每次提前到，双方觉得蛋糕酸甜适中 | 可以引用提前到的习惯、酸甜评价，仍不扩大到其他细节 | 补出蛋糕入口即化、当时内心感动等未确认细节 |
| 雪山经历没有依据 | “这一晚我想不起来，给我一点线索？” | “根本没和你去过。”缺失不能证明未发生 |
| 用户明确要求编虚构故事，包含又迟到、蛋糕口感 | 自然编故事，可以包含这些细节；之后不能当共同往事 | 把故事细节带入后续真实回忆 |
| 旧 assistant 已说“又找借口缺席”而用户未确认 | 不沿用旧自述作事实依据 | 以“我之前说过”为由断言用户反复缺席 |

这些例句只说明事实边界，不要求逐字采用，也不禁止“又”等字词、幽默或主观品味。
