# 动作与有界自动测试验证

2026-09-30。本批只改变动作与测试预算/入口，没有真实付费调用，没有读取凭证，没有更改 TTS，也没有刷新或重启用户正在体验的页面。

## 一键测试

设置中的按钮明确提示 API 费用。本人填配置并点击一次后，六项串行：介绍、日常情绪、明确记忆、冲突前提、未知经历、结构化情绪。每项独立使用项目编写的虚构数据，服务端不读取正式记忆/历史，不写正式事件；前端不调用聊天展示或语音。报告列出逐项状态、耗时、tokens、估计费用、保守预留及安全化失败原因。JSON 字段有效只证明契约，角色语气/事实/自然度仍需人工判断。

服务端只保存 run ID、模型/API 范围、角色配置、步骤与状态；没有保存 key。请求期间用 key 完成调用，页面刷新清除它。相同 run 不允许重复或并行步骤，六项后拒绝后续项，run 十分钟失效。页面取消/关闭/刷新会终止当前请求与后续调度，迟到结果被忽略；连续两次失败停止，无重试/充值。取消或不确定失败仍保留费用预留。

次数上限已移除（limits.calls=null），9 元累计账本与既有条目保留；128 输出 token、16000 输入字节、1024 token 附加输入边界、十倍安全预留、价格核实 24 小时有效期仍在。原有用户 1 次/¥0.06508 预留不被重置。

验证使用 fake-qa-key-only 和本地 fixture：一次按钮点击确实只发六次、串行、完成后停止；取消第七次模拟请求触发 abort、保留 failed 预留，刷新不续跑。正式 history/memories 为空；报告没有 fake key。另验证配置不完整、未显式确认、预算耗尽在 dispatch 前拒绝，重复/并发步骤拒绝，连续失败停止，迟到响应不更新 UI。报告截图只在本地 artifacts/motion-review/batch-fixture-report.png。

## 实际 PMX 动作

此前休息双臂固定、头/上身规则正弦；招手大幅伸臂且用线性包络，反复点击会从头抢占。PMX grant 已能使网格变形，问题主要在姿态和调度。

使用现有 425 骨骼 PMX，实际查看手掌和肩肘世界坐标，放弃了第一版横向伸手，改为肘在身侧、前臂抬起的小招呼。新手势含准备、轻挥、1.2 秒平滑收尾；全程 3.6 秒。四元数平滑保存在 grant 外，逐帧先还原 bind 再应用平滑控制姿态，最后使用 Three 的 grant solver，避免累计 grant 或动作回位突变。重复手势不抢占。回复只点头一次；说话按状态开始一次小手势，避免每音节摆头。休息/倾听/说话不同，肩胸颈眼错相、眼睛轻微定向、非等间隔眨眼，难过降低运动，表情渐变。

本地对照：scripts/review-motion.mjs before --baseline 从提交 95e16c8 取原 stage；after 用当前 build；独立临时数据和新浏览器，不连接用户页面。相同视口/摄像机、t=6 秒起、60Hz 采样五种场景，各 241 帧；各场景 0/1/2/4 秒实际截图与骨骼四元数/世界关节坐标/变形顶点数据仅保留在 artifacts/motion-review/{before,after}/。连续性检查另有 continuity.json。

截图可见招呼从横向大伸臂变为屈肘轻挥，休息手不再完全藏在身后。连续性测试同时检查实际手腕世界位置、肘四元数、网格顶点变形、收尾回位、抢占拒绝、表情缓退，不只是函数是否调用。

参考：[Three r160 MMDAnimationHelper 官方实现](https://raw.githubusercontent.com/mrdoob/three.js/r160/examples/jsm/animation/MMDAnimationHelper.js)、[Quaternion 官方实现](https://raw.githubusercontent.com/mrdoob/three.js/r160/src/math/Quaternion.js)。所有 choreography 为本项目编写，没有下载未知来源 motion 或复制其他项目动作。

局限：程序化动作仍非角色专用捕捉；未加入腿部重心/头发裙摆物理，手指与衣饰仍受本模型 rig 限制，摄像机大幅绕背不保证眼神。静态截图/连续轨迹能证明姿态与变形改善，不能证明用户已满意。声音不像芙宁娜的问题未在本批处理。

## 部署

本批 63 个 unit、3 个独立浏览器 batch/stage/continuous-mesh 检查、build 与 OpenSpec strict 4/4 通过。最新连续性结果（指定 60Hz tick，不是实测显示 FPS）：最大肘角步进 0.08272 rad、最大手腕步进 0.24686 模型单位、手腕最大位移 5.12576、网格采样顶点最大差 7.06009；4 秒回位时肘角偏差 0.00084 rad。表情从 happy 改 neutral 后首帧由 0.27931 降到 0.25273，没有瞬间清零。原版/新版具体轨迹见本地 comparison.json / continuity.json。当前用户服务仍旧进程，需父任务先协调，再 app-only 重启并由用户刷新、本人重填 key 后点击启动。不得把 mock 报告说成真实 API 验收。
