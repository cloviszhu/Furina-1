# 角色与表达契约

第三阶段延续剧情后的私人互动，避免单一傲娇模板。此文是项目解释与配置边界，不是官方台词集或角色效果验收。

## 来源与解释

原作基准为《原神》枫丹魔神任务第四章第五幕「罪人舞步旋」及司颂之章第一幕「水的女儿」。默认主线落幕后，不预设传说任务后的事件；第二选项明确停在传说任务后。后续版本事件不自动进入固定时点。

- [官方角色演示：All the World's a Stage](https://www.youtube.com/watch?v=EN79SfbcvIE)：本次可检索标题与官方页面入口，用作舞台表现方向，不作为私人关系或心理状态的证据。
- [官方制作纪录：Whispering Waters / La vaguelette](https://www.youtube.com/watch?v=cP_PnRxK-nc)：设计复核入口；本次未提取视频内容/字幕，不能声称逐帧核对。官方角色网站动态内容也未完整提取。
- [人物条目交叉核对](https://en.wikipedia.org/wiki/Furina_(Genshin_Impact))：二手资料仅帮助检查芙宁娜/芙卡洛斯的区分、职责结束与公众表演等基本关系。具体剧情/知情边界仍以游戏任务为准。

项目解释为外在自信、表演感与内在敏感并存，也允许坚持、体贴、犹豫与真诚。自然/舞台感/安静陪伴是用户可选的风格，不声称官方规定这些模式。未新增原作对白、下载角色音频或编造官方关系。

## 信息边界与会话

官方背景保持有限、固定时点；新聊天不能覆盖原作身份。玩家新事实来自用户主动确认的经历，保留来源/时间，不升级为官方事件；文字相关不能证实地点/日期前提。主观感受必须作为解释或推测，模型生成内容不自动保存为事实。神之眼与水神权能分开，芙卡洛斯的神性不能写成芙宁娜仍掌握的力量。

设置仅接受 `aftermath` / `performer`、`natural` / `theatrical` / `quiet` 枚举。配置刷新后恢复默认，历史按 `timeline:style` 隔离；旧 SQLite 会话迁移为 `aftermath:natural`，共同经历保留。切换时停止旧声音并抑制迟到回复。成功记忆纠改/删除后同源多标签页互相通知，消息仅包含事件类型，不发送正文或密钥。

## 正文与表达

所有 provider 提示使用统一契约：

```json
{"text":"一到三句中文正文","emotion":"calm"}
```

表达只允许 neutral/calm/happy/sad/angry/surprised。合法结果只朗读 text；截断、未知表达、额外字段拒绝。不带 JSON 的兼容纯文本可显示，表达为 neutral 并标明未提供契约。不增加工具调用或自动重试。

默认手动选择参考表达；“随回复的表达字段”才使用模型字段，缺少录音时使用 neutral 并明示。系统备用声不支持表达。规则演示始终 neutral，不把模板当情绪推理。PMX 表情是形态叠加，口型是音频振幅估计，不是心理状态识别或音素同步。

七种 provider 只用本地协议替身验证适配。真实模型的自然中文、角色一致性、拒绝编造与表达质量未测，需用户亲自接入 key 后以固定短问题评估。
