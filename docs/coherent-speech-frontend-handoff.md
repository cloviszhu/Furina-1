## 行为与状态边界

idle → thinking → preparing → speaking → preparing（下一段）→ speaking → idle。失败 → error；停止任意阶段 → idle，整轮失效。
模型等待不称 listening，口型幅度不决定说话生命周期。静音音频仍保持 speaking。
每轮生成新UUID；/api/chat 返回的完整段落合同经身份、顺序、长度、emotion及完整拼接验证后接入。不是LLM token stream。
/api/speech携带turnId/segmentId和精确段落文本，最多预取下一句。字幕、表情、首次应答点头在实际音频start时开始；ended推进下一句。取消立即停源、清口型/字幕/动作，abort模型与音频并POST /api/turns/:id/cancel。迟到fetch、解码与旧ended均拒绝。
声音试听仍使用旧无turn API和本地短句切分。正式交谈使用服务端原段落，不二次切分，以符合严格文本相等合同。
失败不重试、不换声线，错误阶段允许下一轮。取消确认失败会如实提示，付费模式/预算/记忆/声线删除恢复仍保留。
