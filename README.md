# Project Exo · 数字芙宁娜

制作以原神芙宁娜为角色的 AI 伙伴：能够动作、真实发声，并积累与用户的共同经历。角色以原有设定为起点，新的经历能影响后续互动；具体成长边界仍待讨论。

当前处于需求探索和实施准备阶段，没有业务实现。用户仍在继续补充需求，平台、引擎、模型服务及首版范围均未确定。用户提供的两份 PMX 2.0 角色模型已整理至 `assets/characters/furina/source/mmd/`，详情见 [资产检查](docs/assets.md)。

已确认方向：动作系统、真实语音、记忆与人设都重要，文本对话不足以完成目标；包含声音训练系统规划，素材和授权来源待定。参考 [D_sakiko](https://github.com/MacchaPafe/D_sakiko)，本项目人物是芙宁娜。

开发优先使用 OpenSpec。本机 CLI 1.13.1 已验证并在项目初始化，采用 `spec-driven` schema。当前没有正式 change 或已实现规格，候选行为与环境证据见 [实施准备](docs/preparation.md)。

后续顺序：继续收集需求与检查真实资产 → 写明本次变更的规格、设计、任务和验收 → 实现并核验 → 归档。若某项工作明显不适合 OpenSpec，记录原因。规格结构检查通过不代表角色效果已经验收。
